# Župna Matica – izdanja

Program za župni ured: matične knjige (krštenih, prvopričesnika, potvrđenih, vjenčanih, umrlih, primljenih u puno zajedništvo), obiteljski kartoni, blagoslov kuća, isprave na HBK obrascima i statistika.

Ovdje se nalaze **samo instalacijske datoteke** programa. Podaci župe **nikad** ne idu na internet: baza je šifrirana lozinkom i ostaje na računalu župe.

## Instalacija
1. Otvori **[Releases](../../releases)** → najnovija inačica → **Assets**.
2. Preuzmi `Zupna-matica-Setup-<inačica>.exe` i pokreni ga.
3. Ako Windows prikaže „Windows je zaštitio vaše računalo” → **Više informacija → Ipak pokreni**
   (program nije potpisan certifikatom).
4. Pri prvom pokretanju upišite podatke svoje župe i smislite lozinku baze.

Poveznice „Source code (zip / tar.gz)” koje GitHub sam dodaje sadrže samo ovu datoteku – ne trebaju.

## Ažuriranje
Instalirani program sam provjerava ima li nove inačice i nudi gumb **„Ažuriraj”**.
Prije ažuriranja radi se sigurnosna kopija baze; podaci ostaju na računalu.
